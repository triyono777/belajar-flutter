# belajar-flutter

Kumpulan **latihan & materi belajar Flutter/Dart** dalam bahasa Indonesia — terbuka untuk siapa saja, dirancang khusus **ramah kontributor pemula** (mahasiswa, self-learner, siapa pun).

Tujuannya sederhana: bikin satu tempat yang mudah diakses untuk latihan terstruktur, dan jadi ruang latihan kontribusi open source pertama bagi banyak orang.

## Untuk siapa?

- Pemula yang baru belajar Flutter dan ingin contoh yang runut.
- Kontributor pertama yang ingin PR pertamanya di-merge tanpa takut ribet.

## Cara berkontribusi

Kami menjaga aturan kontribusi sesederhana mungkin:

1. Baca [CONTRIBUTING.md](CONTRIBUTING.md).
2. Lihat label [`good first issue`](https://github.com/triyono777/belajar-flutter/labels/good%20first%20issue) dan [`tambah-latihan`](https://github.com/triyono777/belajar-flutter/labels/tambah-latihan).
3. Klaim satu issue, buat PR kecil, selesai. Kami review dengan sabar.

Tidak harus jago. Salah bikin PR itu bagian dari belajar — kami bantu perbaiki.

## Struktur repo

```
exercises/
  01_hello_dart/        # contoh latihan lengkap (referensi)
  ...
```

Setiap folder latihan berisi `README.md` (instruksi) dan starter code. Index lengkap ada di [exercises/README.md](exercises/README.md).

## Menjalankan latihan

Butuh [Flutter SDK](https://docs.flutter.dev/get-started/install). Untuk latihan Dart murni:

```bash
dart run exercises/01_hello_dart/main.dart
```
