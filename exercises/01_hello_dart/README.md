# 01 — Hello Dart

**Tujuan:** memahami variabel, fungsi, dan output dasar di Dart.

## Instruksi

1. Buat variabel nama dan umur.
2. Buat fungsi `sapa(nama)` yang mengembalikan `"Halo, <nama>!"`.
3. Cetak hasilnya ke konsol.

## Jalankan

```bash
dart run exercises/01_hello_dart/main.dart
```

## Contoh output

```
Halo, Triyono!
Umur saya 30 tahun.
```
